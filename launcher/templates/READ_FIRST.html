Rain or Shine

Hong Kong weather markets on the Sepolia test network. 香港天气预测市场，运行在 Sepolia 测试网。

@@SYSTEM@@

Start

  1. Unzip the whole file.
  2. Open @@START@@. If macOS blocks it, open System Settings, then Privacy & Security, and click Open Anyway. If Windows shows a warning, click More info, then Run anyway.
  3. The app opens in your browser. Keep the black window open while you use it.
  4. Use Chrome or Edge with MetaMask. Switch MetaMask to Sepolia.

What you can do

  • Anyone can browse markets, bet Yes or No with Sepolia test ETH, and claim winnings.
  • The admin account creates markets.
  • The market's proposer submits the result after the Hong Kong Observatory publishes it. @@WEATHER@@ downloads the file to import.

If something goes wrong

  • No page opened? Copy the address shown in the window into your browser.
  • Wrong network? Switch MetaMask to Sepolia.
  • Still stuck? Send us launch-report.log from this folder.

开始

  1. 完整解压压缩包。
  2. 打开 @@START@@。如果 macOS 阻止打开，请进入“系统设置”的“隐私与安全性”，点击“仍要打开”。如果 Windows 弹出提示，点击“更多信息”，再点击“仍要运行”。
  3. 浏览器会自动打开应用。使用期间请不要关闭黑色窗口。
  4. 请使用装有 MetaMask 的 Chrome 或 Edge，并把网络切换到 Sepolia。

可以做什么

  • 所有人都可以浏览市场，用 Sepolia 测试 ETH 押 Yes 或 No，结算后领取。
  • 管理员账户负责创建市场。
  • 天文台发布数据后，由市场指定的提交者提交结果。@@WEATHER@@ 用来下载要导入的天文台文件。

遇到问题

  • 网页没有打开：把窗口里显示的地址复制到浏览器。
  • 网络不对：在 MetaMask 中切换到 Sepolia。
  • 仍然不行：把本文件夹里的 launch-report.log 发给我们。
